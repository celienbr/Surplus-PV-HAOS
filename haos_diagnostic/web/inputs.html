Archives et journaux

Les 48 dernières heures restent dans la base active ; les données antérieures sont archivées et restent consultables. Les logs techniques sont conservés 7 jours.

Recherche d'archives…

Exporter l'historique vers Excel

Export des données enregistrées sans réduction du nombre de points. Pour le réseau, il comprend les 48 h récentes et les données archivées, avec la date, l'heure suisse, le réseau signé, l'achat, l'injection, les défauts la demande de chauffe et les anciennes valeurs virtuelles archivées.

Période maximale : 31 jours par export. Les périodes sans mesures restent vides.

Excel : ouvrir le CSV directement ou utiliser Données → À partir d'un fichier texte/CSV. Les puissances signées sont numériques ; une injection correspond à une valeur négative. Les colonnes de chauffe indiquent des demandes ou des estimations, pas des mesures.
